# Анализ пожаров в России

## О чём проект
Исследование датасета с записями о пожарах: типы пожаров, погодные
условия (температура, осадки, влажность, ветер), географическое
распределение по координатам. 
ИФОРМАЦИЯ СКАЧАНА С САЙТА https://data.rcsi.science/data-catalog/
Все данные были в открытом доступе.

## Данные
Файл `data/FiresRu.csv` содержит записи о пожарах со следующими
столбцами:
- `type_name` — название типа пожара (Forest fire, Natural fire и т.д.)
- `type_id` — числовой идентификатор типа
- `lat`, `lon` — широта и долгота
- `temperature_c` — температура, °C
- `precipitation_mm` — осадки, мм
- `relative_humidity` — относительная влажность, %
- `wind_speed_ms` — скорость ветра, м/с
- `solar_radiation` — солнечная радиация

## Что делает каждый файл

###  fires_exploration.py — исследование данных
- Читает CSV.
- Строит **столбчатую диаграмму** количества пожаров по типам.
- Строит **ящик с усами** (boxplot) температуры по типам пожара.
- Готовит данные для **карты пожаров**: склеивает широту и долготу
  в ключ, строит сводную таблицу по координатам и типам.
- Сохраняет итоговую таблицу в `output/fires.csv`.

### distribution_analysis_fires.py
 — анализ распределений
- Читает CSV.
- Находит **выбросы по осадкам** методом IQR (межквартильный размах).
- Строит сетку 2×2 из графиков:
  - гистограмма температуры;
  - гистограмма осадков (без выбросов);
  - гистограмма влажности;
  - распределение скорости ветра по типам пожара (seaborn).
- Строит **3D-график**: солнечная радиация × влажность × осадки.
- Сохраняет картинки в `output/figures/`.

## Как запустить
1. Установить зависимости:
pip install -r requirements.txt

2. Запустить первый файл:
python distribution_analysis_fires.py

3. Запустить второй файл:
python fire_investigation.py

4. Результаты появятся в папке `output/`.
